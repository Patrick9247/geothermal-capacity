# 地热产能计算记录表

表名：`heat_flow_records`

| 字段 | 备注 |
| --- | --- |
| id | 记录序号 |
| time | 时间 |
| p1_mpa | P1（地热水压力 MPa） |
| t1_c | T1（地热水温度 ℃） |
| p2_mpa | P2（地热蒸汽压力 MPa） |
| t2_c | T2（地热蒸汽温度 ℃） |
| w1_kg_s | W1（地热水质量流量 kg/s） |
| w2_kg_s | W2（地热蒸汽质量流量 kg/s） |
| qw_mw | Qw（地热水热流量 MW） |
| qs_mw | Qs（地热蒸汽热流量 MW） |
| q_total_mw | Q总（总产能：Qw + Qs，MW） |
